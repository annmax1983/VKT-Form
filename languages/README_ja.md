# vkt-form
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

ブラウザフォームスナップショット記憶入力プラグイン — ワンクリックでフォームを保存し、ワンクリックで入力。すべてのデータはブラウザにローカル保存。

> Chromium ベース · Manifest V3 · トラッキングなし · ユーザー手動トリガー

---

## なぜ vkt-form？

毎回同じフォームに入力するのは面倒です。vkt-form で一度保存すれば、いつでもワンクリックで入力できます。

| 利点 | 詳細 |
|------|------|
| 🔒 **プライバシー優先** | すべてのデータはブラウザにローカル保存。サーバー、アップロード、トラッキングなし。 |
| ⚡ **ワンクリック操作** | 「収集」ボタンで保存、「入力」ボタンで復元。 |
| 🧠 **スマートマッチング** | name属性優先、DOM順序フォールバック、Vue/React対応。 |
| 💾 **データ紛失防止** | JSONエクスポート/インポート対応。 |
| 🆓 **無料で利用可能** | 無料版：5スナップショット、毎日20回入力。 |
| 🌍 **6言語対応** | ブラウザの言語を自動検出。 |

## 機能一覧

| 機能 | 説明 |
|------|------|
| 📋 **フォーム収集** | ボタンでトリガー、ページの全 `input/select/textarea` をスキャンして保存。 |
| ⚡ **スマート入力** | 第一優先：`name` 属性マッチ、フォールバック：`domIndex + tagName + type`。 |
| 🔄 **フレームワーク対応** | `input`、`change`、`click` イベント発火、Vue/React対応。 |
| 📊 **クォータ管理** | 無料版：5スナップショット、毎日20回。プレミアムは無制限。 |
| 🔑 **ライセンス解除** | 設定ページでキー入力してプレミアム有効化。 |
| 📥📤 **インポート/エクスポート** | JSON形式バックアップ。 |
| 🌐 **URL正規化** | クエリ・フラグメント除去、小文字化、hash保持オプション（SPA用）。 |
| 🌍 **多言語** | English、中文、日本語、Español、Deutsch、Français。 |

## インストール

### 開発者モードで読み込み

1. ブラウザの拡張機能ページを開く：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 右上の **デベロッパーモード** をON
3. **パッケージ化されていない拡張機能を読み込む** をクリック、`vkt-form` フォルダを選択
4. ツールバーにアイコン表示

---

## 使い方

### フォームスナップショットの保存

1. フォームがあるページにアクセス
2. ツールバーのアイコンをクリック
3. **🔄 収集** ボタンをクリック
4. フォームフィールドがスキャン・保存される

### 自動入力

**方法A：現在のページにマッチ**
1. 以前保存したページに戻る
2. **⚡ 入力** ボタンをクリック
3. 対応するスナップショットが自動入力

**方法B：特定スナップショットを入力**
1. リストから対象レコードを探す
2. **この項目を入力** をクリック
3. そのスナップショットで強制入力

## プライバシー

- ✅ **データアップロードなし** — `chrome.storage.local` にローカル保存
- ✅ **手動トリガー** — 自動収集なし、ボタンクリック時のみスキャン
- ✅ **トラッキングなし** — テレメトリ、リモート呼び出しなし
- ✅ **最小権限** — `storage` と `activeTab` のみ

---

## 権限の説明

| 権限 | 用途 |
|------|------|
| `storage` | スナップショットと設定のローカル保存 |
| `activeTab` | ボタンクリック時のみ現在のタブにアクセス |
