# VKT Form — フォームスナップショット＆自動入力

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

Webフォームのスナップショットを保存し、後から自動入力できるブラウザ拡張機能です。データは既定でブラウザ内に保存されます。Premium では Chrome/Edge アカウント経由でデバイス間のスナップショット同期を任意で有効にできます。

## 機能一覧

- **ワンクリックフォーム収集** — 任意のページ上のすべてのフォームフィールドをスキャンして保存
- **深いフィールド検出** — Shadow DOM、iframe、リッチテキストエディタに対応。多段階フォームの非表示ステップも収集します
- **フレームワークを理解する自動入力** — ネイティブセッターとブラウザ自身の編集パイプライン経由で書き込むため、Vue / React / Angular の制御コンポーネントでも状態が実際に更新されます
- **書き込み後の検証** — 書き込んだ後に必ず値を読み返します。失敗は黙って無視せず報告します
- **フィールド調整** — ページ上の要素に一度紐づければ、以後は必ず入力されます
- **ローカル優先** — スナップショットは `chrome.storage.local` に保存され、Premium の同期を有効にしない限りアップロードされません
- **スナップショットと入力は無制限** — 無料版に制限はありません
- **エクスポート/インポート** — JSON バックアップと復元はすべてのユーザーが無料で利用可能
- **デバイス間同期（Premium）** — Chrome/Edge アカウント経由の任意同期。独自の同期サーバーはありません

## 動作の仕組み

1. フォームのある任意のページにアクセスし、**収集**をクリックしてスキャン＆保存
2. 後でそのページに戻り、**入力**をクリックしてすべてのフィールドを自動入力
3. サイドパネルのリストでスナップショットを管理（特定のものを入力、更新、調整、削除）

## フィールド一致

保存済みの各フィールドはページ上のすべてのフィールドと採点され、信頼度のしきい値を超えた最良の候補が選ばれます。しきい値未満は「見つかりません」として報告され、間違った欄に書き込まれることはありません。

重み付けの目安：

- `name`、`id`、`autocomplete` 属性
- ラベル文字列、`aria-label`、囲む `<label>`、プレースホルダー、周辺テキスト
- 意味トークン（`username`、`phone`、`email`、`address` など。中国語・英語対応）
- 構造パス、および表の行など繰り返しコンテナ内の行・列位置
- 最後の手段としてのDOM順序

位置ではなく記述子で照合するため、サイトがフィールド名を変更したり、フォームの順序を入れ替えたり、別のURLで配信してもスナップショットは機能します。

## 入力

各フィールドは段階的に強い手法で書き込まれ、毎回値を読み返して検証します：

1. **ネイティブセッター＋イベント** — `HTMLInputElement.prototype` のセッター経由で書き込み、`beforeinput` / `input` / `change` を発火。プロトタイプ経由にすることが、React の変更追跡を実際に反応させる鍵です。
2. **確定トリガー** — フォーカスを外した時だけ保存するコンポーネント向けに `blur` / `focusout`。
3. **本物の編集パイプライン** — フォーカスと選択の後に `document.execCommand('insertText')`。生成されるイベントは実際のタイピングと区別できません。リッチテキストエディタもこの方法で入力します。
4. **コンポーネントアダプター** — div ベースのセレクト（Element Plus、Ant Design、Arco、Naive UI、Vant など）では、人間と同じようにリストを開き、保存された値の選択肢をクリックします。
5. **デバッガーモード** — 初期状態はオフ。他のすべてを拒否するコンポーネント向けに、ブラウザのデバッガーで信頼された入力イベントを発生させます。Chrome はこの権限の実行時申請を許可していないためインストール時に付与されますが、モードを有効にするまで使用されず、入力完了後は即座に切断されます（接続中はブラウザにデバッグバナーが表示されます）。

最初のパスで見つからなかったフィールドは数秒間再試行されるため、遅れて描画されるフォームや条件付きで表示されるフィールドも入力されます。

## フィールド調整

ほとんどのページはヒューリスティックで対応できます。残りは調整機能で解決します。スナップショットの 🎯 パネルを開き、フィールドを選んで **紐づけ** をクリックし、ページ上の該当する入力欄をクリックします。紐づけはスナップショットに保存され、以後サイト側が何を変更しても常に優先されます。

## URL正規化

スナップショットのキーは自分で付けた名前で、各スナップショットはページの正規化URLを保存します。そのURLでページとひも付けられるため、同じページに複数のスナップショットを保存できます：
- クエリ文字列とフラグメントを除去
- ドメインを小文字に変換
- 末尾のスラッシュを正規化
- オプション：SPAアプリ向けにハッシュルートを保持（設定でトグル）

## デバイス間同期（Premium）

Premium のスナップショットは、ブラウザ内蔵の `chrome.storage.sync` を使い、Chrome/Edge アカウント経由でデバイス間に同期できます。当方の同期サーバーはありません。データはブックマークや設定と同じく、ブラウザ提供元のアカウント同期サービスに保存されます。

- **設定 → デバイス間同期** で有効にします。Chrome または Edge にサインインしている必要があります。
- 同期をオフにしても、ローカルのスナップショットは無制限に保存・編集できます。
- 容量はブラウザ側の制限（1 項目 8 KB、合計約 100 KB）に従うため、大きなスナップショットは分割されます。収まらないスナップショットはローカルに保存されたままで、パネルに通知が表示されます。
- 削除も同期されます：同期が有効なときに削除したスナップショットは、他のデバイスからも削除されます。
- 機密性の高い値も平文で保存され、他のフィールドと同様に同期されます。
- 同期をオフにすると以降の同期は停止しますが、ブラウザアカウントに既にあるコピーは削除されません。

## ライセンス

無料版：ローカルスナップショット、入力、調整、JSON エクスポート/インポートは無制限。Premium ではブラウザアカウント経由のデバイス間同期と優先サポートが利用できます。
