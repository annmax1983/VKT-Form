# vkt-form
[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

浏览器表单快照记忆填充插件 — 一键保存表单，一键回填。数据默认保存在浏览器本地；高级版可选通过 Chrome/Edge 账号在设备之间同步快照。

> 基于 Chromium · Manifest V3 · 无追踪 · 用户手动触发采集

---

## 为什么选择 vkt-form？

每次注册、登录都要重复填写相同的表单太烦了。vkt-form 让你保存一次，以后一键回填。

| 优势 | 详情 |
|------|------|
| 🔒 **隐私优先** | 数据默认全部存储在浏览器本地，不上传、无追踪。只有你主动开启高级版跨设备同步时，快照才会进入浏览器账号的同步服务。 |
| ⚡ **一键操作** | 点击「刷新收集」保存表单，点击「填充」一键回填。 |
| 🧠 **智能匹配** | 按 name/id/autocomplete、标签文字、语义词、结构路径综合打分匹配，而非死记位置。Vue/React 后台表单改了字段名、换了路由也照样填得上。 |
| 🎯 **字段校准** | 算法搞不定的页面，手动绑定一次，之后永远填得上。 |
| ✅ **填完自检** | 每个字段写完都会读回校验，失败会明确列出来，绝不假装成功。 |
| 💾 **数据不丢失** | 支持 JSON 导出导入备份（免费）；高级版还可跨设备同步。 |
| 🆓 **免费可用** | 快照数量、填充次数均不限制。 |
| 🌍 **6 种语言** | 自动识别浏览器语言。 |

## 功能特性

| 功能 | 说明 |
|------|------|
| 📋 **深度采集** | 扫描页面全部 `input/select/textarea/富文本编辑器`，穿透 Shadow DOM 与 iframe；多步表单里未显示的那几步也会一并采集。 |
| 🧠 **打分匹配** | 每个已存字段与页面上每个候选字段逐一打分，超过阈值才写入；分数不够就报「未找到」，而不是填错框。 |
| ⚡ **分级回填** | 依次尝试：原生 setter + 事件 → blur 提交触发 → 浏览器真实编辑管线（`execCommand`）→ 下拉组件适配器 →（可选）调试器模式，每级都读回校验。 |
| 🔄 **框架兼容** | 通过 `HTMLInputElement.prototype` 的原生 setter 写入，React 的变更追踪才会真正触发；受控组件、只读下拉都能处理。 |
| ⏱️ **延迟补填** | SPA 路由切换后才渲染的表单、点了某选项才出现的条件字段，会在填充后几秒内持续重试。 |
| 🎯 **字段校准** | 在快照的 🎯 面板里选字段→点「绑定」→在页面上点那个输入框，绑定关系存进快照并优先于所有算法。 |
| ☁️ **跨设备同步（高级版）** | 通过 Chrome/Edge 账号自带的同步服务同步快照，无需自建同步服务器。 |
| 🔑 **License 解锁** | 在设置页面输入密钥激活高级版，解锁跨设备同步和优先支持。 |
| 📥📤 **导入导出** | JSON 格式备份和恢复，免费版同样可用。 |
| 🌐 **URL 归一化** | 去除查询参数、锚点，域名小写，可选保留 hash 路由（SPA 模式）。 |
| 🌍 **多语言** | English、中文、日本語、Español、Deutsch、Français。 |

## 使用方法

### 保存表单快照

1. 访问包含表单的网页
2. 点击工具栏的 vkt-form 图标，打开侧边栏
3. 点击 **🔄 刷新收集** 按钮
4. 页面表单字段被扫描并保存

### 自动填充

**方式 A：匹配当前页面**
1. 回到之前保存过快照的页面
2. 点击 **⚡ 填充** 按钮
3. 自动匹配对应快照并填充

**方式 B：填充指定快照**
1. 在快照列表中找到目标记录
2. 点击 **填充** 按钮
3. 强制使用该快照填充当前页面

### 校准识别不了的字段

算法覆盖不到的长尾页面，手动绑定一次即可：

1. 先打开要填充的那个页面
2. 在快照列表里点该记录右侧的 **🎯** 按钮
3. 在面板中选中识别不了的字段，点 **绑定**
4. 页面顶部会出现提示条，点击页面上真正的那个输入框（Esc 取消）
5. 绑定保存在快照里，之后每次填充都优先使用它

### 管理快照

- **更新**：重新扫描当前页面，覆盖已有快照
- **校准**：为识别不到的字段手动绑定页面元素
- **删除**：删除不需要的快照
- **导出**：下载所有快照为 JSON 文件
- **导入**：从 JSON 文件恢复快照

## 隐私保护

vkt-form 以隐私为核心设计原则：

- ✅ **本地优先** — 默认所有数据存储在 `chrome.storage.local`，不上传
- ☁️ **同步是可选的** — 只有高级版用户在设置里主动开启跨设备同步后，快照才会通过 Chrome/Edge 账号的 `chrome.storage.sync` 同步；数据进入浏览器厂商的账号同步服务，不经过我们的服务器
- ✅ **用户手动触发** — 不自动采集，必须点击按钮才扫描
- ✅ **无分析追踪** — 无遥测、无统计上报；对外请求只有 License 密钥校验，以及开启同步后的浏览器账号同步
- ✅ **按需注入** — 不注册常驻内容脚本，仅在用户点击时向当前页面注入
- ✅ **调试器模式默认关闭** — 安装时即授予调试权限（Chrome 不允许运行时申请），但只有在设置里主动开启后才会使用，填充结束立刻断开

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 本地保存表单快照和设置；开启高级版同步后，也用于浏览器的同步存储 |
| `activeTab` | 仅在用户点击按钮时访问当前标签页 |
| `sidePanel` | 显示侧边栏操作界面 |
| `scripting` | 按需向当前页面（含其中的 iframe）注入采集/填充脚本 |
| `debugger` | 用于兼容极端顽固组件的「调试器模式」。Chrome 不允许调试权限运行时申请，因此安装时即授予；但只有你在设置里主动开启后才会真正调用，填充结束立刻断开（填充期间浏览器会显示调试提示条） |

## 跨设备同步（高级版）

高级版快照可以通过 Chrome/Edge 账号在设备之间同步，底层使用浏览器自带的 `chrome.storage.sync`。我们没有同步服务器：数据进入浏览器厂商的账号同步服务，和书签、设置的存放位置相同。

- 在 **设置 → 跨设备同步** 中开启，需要浏览器已登录 Chrome/Edge 账号。
- 关闭同步时，本地快照仍可无限保存和编辑。
- 配额由浏览器决定（单项 8 KB，总量约 100 KB），较大的快照会被拆分为多块。放不下的快照仍会保存在本地，面板会提示。
- 删除也会同步：开启同步时删除的快照会从其他设备上移除。
- 敏感字段以明文保存，开启同步后会和其他字段一样被同步。
- 关闭同步只会停止后续同步，不会删除浏览器账号中已有的副本。
