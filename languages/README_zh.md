# WebFormKeeper
[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

浏览器表单快照记忆填充插件 — 一键保存表单，一键回填。全部数据存储在浏览器本地，不上传云端。

> 基于 Chromium · Manifest V3 · 无追踪 · 用户手动触发采集

---

## 为什么选择 WebFormKeeper？

每次注册、登录都要重复填写相同的表单太烦了。WebFormKeeper 让你保存一次，以后一键回填。

| 优势 | 详情 |
|------|------|
| 🔒 **隐私优先** | 所有数据存储在浏览器本地。无服务器、无上传、无追踪。 |
| ⚡ **一键操作** | 点击「刷新收集」保存表单，点击「填充」一键回填。 |
| 🧠 **智能匹配** | name 属性优先匹配，DOM 序号降级兜底，兼容 Vue/React。 |
| 💾 **数据不丢失** | 支持 JSON 导出导入备份。 |
| 🆓 **免费可用** | 免费版支持 5 条快照、每日 20 次填充。 |
| 🌍 **6 种语言** | 自动识别浏览器语言。 |

## 功能特性

| 功能 | 说明 |
|------|------|
| 📋 **表单采集** | 点击按钮触发，扫描页面全部 `input/select/textarea` 控件，保存字段名、值、类型、DOM 序号。 |
| ⚡ **智能回填** | 第一优先级：`name` 属性匹配；降级策略：`domIndex + tagName + type` 匹配。 |

| 📊 **配额管理** | 免费版：5 条快照、每日 20 次填充；高级版无限制。 |
| 🔑 **License 解锁** | 在设置页面输入密钥激活高级版。 |
| 📥📤 **导入导出** | JSON 格式备份和恢复，数据不怕丢失。 |
| 🌐 **URL 归一化** | 去除查询参数、锚点，域名小写，可选保留 hash 路由（SPA 模式）。 |
| 🌍 **多语言** | English、中文、日本語、Español、Deutsch、Français。 |

## 安装方式

### 开发者模式加载

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择 `WebFormKeeper` 文件夹
4. 工具栏出现 WebFormKeeper 图标

---

## 使用方法

### 保存表单快照

1. 访问包含表单的网页
2. 点击工具栏的 WebFormKeeper 图标
3. 点击 **🔄 刷新收集** 按钮
4. 页面表单字段被扫描并保存

### 自动填充

**方式 A：匹配当前页面**
1. 回到之前保存过快照的页面
2. 点击 **⚡ 填充** 按钮
3. 自动匹配对应快照并填充

**方式 B：填充指定快照**
1. 在快照列表中找到目标记录
2. 点击 **填充本条** 按钮
3. 强制使用该快照填充当前页面

### 管理快照

- **更新**：重新扫描当前页面，覆盖已有快照
- **删除**：删除不需要的快照
- **导出**：下载所有快照为 JSON 文件
- **导入**：从 JSON 文件恢复快照

## 隐私保护

WebFormKeeper 以隐私为核心设计原则：

- ✅ **无数据上传** — 所有数据存储在 `chrome.storage.local`
- ✅ **用户手动触发** — 不自动采集，必须点击按钮才扫描
- ✅ **无分析追踪** — 无遥测、无远程调用
- ✅ **最小权限** — 只申请 `storage` 和 `activeTab`
- ✅ **动态注入** — 不声明 `<all_urls>`，按需注入内容脚本

---

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 本地保存表单快照和设置 |
| `activeTab` | 仅在用户点击按钮时访问当前标签页 |
