Privacy Policy

Effective date: August 2026

Overview

WebFormKeeper is a browser extension that saves and fills web form data. All data is stored locally in your browser using chrome.storage.local. No data is uploaded to any server.

Data Collection

WebFormKeeper collects the following data only when you manually click the "Collect" button:

  • Form field names, values, and types (text, radio, checkbox, select, textarea)
  • The normalized URL of the page where forms are collected
  • DOM element order (domIndex) for fields without a name attribute

Important: The extension does NOT automatically collect any data. All scanning is user-initiated.

Data Storage

Storage KeyContent
wfk_recordsForm snapshots keyed by normalized URL
wfk_metaUsage quotas, license status, daily fill counter
wfk_settingsUser preferences (hash route toggle)

All data remains in your browser's local storage and is never transmitted externally.

Password Fields

WebFormKeeper may capture and store values from password fields if they are present on the page when you click "Collect". These values are stored locally only. Please be aware of this when using the extension on pages containing sensitive credentials.

Permissions

PermissionReason
storageSave form snapshots and settings locally
activeTabAccess the current tab only when you click a button (no persistent access to all sites)

The extension uses chrome.scripting.executeScript to inject content scripts on demand — it does NOT declare <all_urls> or any host permissions.

Third-Party Services

License key validation communicates with api.annmax1983.com to verify premium status. Only the license key, device hash, and plugin ID are sent. No form data or browsing history is transmitted.

Data Deletion

You can delete individual snapshots or all data through the extension popup. Uninstalling the extension removes all stored data.
