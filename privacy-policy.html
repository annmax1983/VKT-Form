Privacy Policy

Effective date: August 2026

Overview

VKT Form is a browser extension that saves and fills web form data. All data is stored locally in your browser using chrome.storage.local. No data is uploaded to any server.

Data Collection

VKT Form collects the following data only when you manually click the "Collect" button:

  • Form field names, values, and types (text, radio, checkbox, select, textarea)
  • The normalized URL of the page where forms are collected
  • DOM element order (domIndex) for fields without a name attribute

Important: The extension does NOT automatically collect any data. All scanning is user-initiated.

Data Storage

Storage KeyContent
vkf_recordsForm snapshots keyed by normalized URL
vkf_metaSnapshot quota and license status
vkf_settingsUser preferences (hash route toggle)

All data remains in your browser's local storage and is never transmitted externally.

Password Fields

VKT Form may capture and store values from password fields if they are present on the page when you click "Collect". These values are stored locally only. Please be aware of this when using the extension on pages containing sensitive credentials.

Permissions

PermissionReason

activeTabAccess the current tab only when you click a button
sidePanelDisplay the extension's side panel UI
scriptingInject the collection/auto-fill script on demand, only when you click a button
debuggerRead and fill form fields reliably on framework-rendered pages (Vue/React). Used only on the tab you act on, only while the action runs
Host permissions (<all_urls>)Let the tool work on whichever site you choose to collect or fill forms on. All processing stays local

The extension uses chrome.scripting and the chrome.debugger API to interact with form fields on the page you are acting on. Form data is never transmitted anywhere — the only external request the extension makes is license-key validation (see below).

Third-Party Services

License key validation communicates with api.annmax1983.com to verify premium status. Only the license key, device hash, and plugin ID are sent. No form data or browsing history is transmitted.

Data Deletion

You can delete individual snapshots or all data through the extension popup. Uninstalling the extension removes all stored data.
