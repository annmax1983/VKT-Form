Privacy Policy

Effective date: October 2026

Overview

VKT Form is a browser extension that saves and fills web form data. All data is stored locally in your browser using chrome.storage.local. No data is uploaded to any server.

Data Collection

VKT Form collects the following data only when you manually click the "Collect" button:

  • Form field names, values, and types (text, radio, checkbox, select, textarea, contenteditable)
  • The URL of the page where forms are collected — both a normalized URL and the raw URL
  • Structural hints used to match the same fields again later: label text, placeholder, nearby text, autocomplete attribute, and a DOM path / DOM order index
  • Whether each field was hidden from view at the moment of collection (framework-hidden inputs and inactive steps of multi-step forms are collected too)

Important: The extension does NOT automatically collect any data. All scanning is user-initiated, and the scan runs only on the tab you are looking at.

Data Storage

Everything the extension stores lives in your browser's chrome.storage.local, under three keys:

Storage KeyContent
vkf_recordsYour saved form snapshots, keyed by the snapshot name you choose. Each snapshot holds: its name, the normalized URL and raw URL of the page, creation and last-update timestamps, a field count, and the field entries (name, id, type, value, collection-time structural hints, DOM order index, hidden flag)
vkf_license_vktformYour license key, its activation status and expiry, and a randomly generated install identifier used to count activation slots. Quota is derived from the number of snapshots in vkf_records, not stored separately
vkf_settingsYour preferences — keep the URL hash when matching snapshots, and optionally type through the debugger API for framework-rendered forms

All data remains in your browser's local storage and is never transmitted externally. There is no cloud component: snapshots are not synced between devices and are not uploaded anywhere. The export/import feature simply writes a JSON file to your own disk and reads one back — that file never leaves your machine unless you move it yourself.

Sensitive Fields

VKT Form does not filter out sensitive fields. If a password, payment card, one-time code (OTP), or other credential is present as a fillable field on the page when you click "Collect", its value is captured and stored — locally, in your browser, in plain text (it is not encrypted). No such value is ever transmitted anywhere by the extension.

Please be aware of this when using the extension on pages containing credentials, and prefer deleting the snapshot once you no longer need it. VKT Form is a form-snapshot tool, not a password manager.

Permissions

The extension uses chrome.scripting and the chrome.debugger API to interact with form fields on the page you are acting on. Form data is never transmitted anywhere — the only external request the extension makes is license-key validation (see below).

Third-Party Services

License key validation communicates with api.annmax1983.com to verify premium status. Only the license key, a randomly generated install identifier, and the plugin ID are sent. No form data or browsing history is transmitted. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

Data Deletion

You delete snapshots from the extension's side panel — each snapshot row has a delete button, and it asks for confirmation first. (There is no popup UI and no "delete everything" button; snapshots are removed one at a time.)

To erase everything at once, uninstall the extension — Chrome removes its local storage with it. Nothing is retained on any server, because nothing was ever sent to one.
